# DicodeFFlow

نسخه بسته: `1.0.0`

صفحه راهنما: [حل ارور Google Flow](https://mcodersir.github.io/DicodeFFlow/)

دانلود نسخه اول: [DicodeFFlow-v1.0.0.zip](https://github.com/mcodersir/DicodeFFlow/releases/download/v1.0.0/DicodeFFlow-v1.0.0.zip)

این بسته بر پایه `CFC-Flow-v1.1.0` آماده شده و فقط از نظر نام، هویت بصری و لینک های برند برای دیکد بازطراحی شده است.

## تغییرات این نسخه

- نام افزونه به `DicodeFFlow` تغییر کرده است.
- لوگوی دیکد به صورت مربع گوشه گرد برای آیکون افزونه و رابط popup استفاده شده است.
- فونت Vazirmatn به صورت محلی داخل افزونه قرار گرفته و رابط فارسی با آن نمایش داده می شود.
- لینک مجله دیکد: `https://dicode.ir/mag`
- لینک تلگرام: `https://t.me/dicodeir`
- لینک یوتیوب: `https://www.youtube.com/@Dicodeir`
- لینک آپارات: `https://www.aparat.com/Dicode`
- فایل های عملکردی اصلی بدون تغییر باینری حفظ شده اند: `app.js`، `engine.js`، `link.js`، `panel.js` و `stat.js`.
- مجوزها، مقصدهای شبکه و منطق اصلی افزونه تغییر نکرده اند.

## نصب محلی در Chrome

1. فایل ZIP را در یک پوشه استخراج کنید.
2. در Chrome به `chrome://extensions` بروید.
3. `Developer mode` را روشن کنید.
4. روی `Load unpacked` بزنید و پوشه استخراج شده را انتخاب کنید.

بعد از نصب، popup افزونه را باز کنید، کلید را روشن کنید و تب Google Flow را دوباره بارگذاری کنید.

## فونت

Vazirmatn با مجوز SIL Open Font License داخل `assets/fonts` قرار گرفته است.

## نکته امنیتی

این بسته hardening عملکردی انجام نمی دهد تا رفتار نسخه اصلی تغییر نکند. کد هسته اصلی obfuscated است و `app.js` همچنان منطق و مقصدهای شبکه نسخه اصلی را دارد؛ بنابراین این بسته به معنای تایید امنیت تولید یا تضمین موفقیت در هر حساب یا شبکه نیست. قبل از نصب، مجوزها و فایل های بسته را بررسی کنید.
